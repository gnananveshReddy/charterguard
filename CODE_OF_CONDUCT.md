# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good faith, and keep criticism
about the work, not the person. Harassment, personal attacks, discriminatory
language and publishing others' private information are not acceptable anywhere
in the project's spaces: issues, pull requests, discussions and any chat linked
from the README.

Security research is welcome here, but attack examples shared in public issues
should demonstrate a detection gap, not target real people, organisations or
systems.

## Reporting

Report conduct concerns privately to the maintainers. Use the contact listed on
the maintainer's GitHub profile, or, if the concern involves a maintainer, GitHub's
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
process. Reports are handled confidentially. The Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
describe the possible responses.
